## 1. Executive Summary

### 1.1 The Problem

The current interpreter attempted a "single-context" architecture where MethodContext and BlockContext were merged. **This approach is fundamentally incompatible with the Blue Book specification and cannot be implemented correctly.**

### 1.2 The Blue Book Solution

The Blue Book (Chapters 28-30) specifies a **two-context architecture**:

1. **MethodContext**: Created for method activations
2. **BlockContext**: Created for block closures with arguments/temps

Blocks execute **inline bytecode** (not separate CompiledMethods), with BlockContext objects created at runtime via the `blockCopy:` primitive (Primitive 80).

### 1.3 Critical Insights

**Blocks are NOT separate CompiledMethods**:
- Block bytecode is **embedded inline** in the method's bytecode stream
- `blockCopy:` creates a BlockContext pointing to a bytecode offset within the method
- Blocks with no arguments/temps execute **without any context** - just inline bytecode

**Two Context Types Are Required**:
- MethodContext: Has a `method` field (CompiledMethod reference)
- BlockContext: Has `initialIP` and `home` fields (bytecode offset + defining context)
- These are **structurally different** - cannot be unified

### 1.4 How Smalltalk-80.st Does It

Examine `Smalltalk-80 Source/Smalltalk-80.st` for actual examples:

**Example 1: Simple whileTrue: loop**
```smalltalk
"Method: Integer>>timesRepeat:"
| count |
count := self.
[count > 0] whileTrue: [
    count := count - 1.
    aBlock value
].

"Generated bytecode:"
; count := self
PUSH_SELF              ; Push receiver
POP_STORE_TEMP 0       ; Store to temp 0 (count)

; Start of outer block: [count > 0]
.L1:
PUSH_TEMP 0            ; Load count
PUSH 0                 ; Load 0
SEND >                 ; Send >
; End of outer block

; Start of conditional block
JUMP_FALSE .L2         ; Exit loop if false

; Inner block: [count := count - 1. aBlock value]
PUSH_TEMP 0            ; Load count
PUSH 1                 ; Load 1
SEND -                 ; Send -
POP_STORE_TEMP 0       ; Store back to count

PUSH_TEMP 1            ; Load aBlock argument
SEND value             ; Send value to block

; End of inner block
JUMP .L1               ; Loop back

.L2:
; Loop exit
```

**Key Observations**:
1. Block bytecode is **inline** in method bytecode
2. No `blockCopy:` calls for simple blocks (no args/temps)
3. Jump instructions control flow
4. Blocks without arguments execute as simple inline code

**Example 2: Block with arguments**
```smalltalk
"Method: Collection>>do:"
^self do: [:each | each printString]

"Generated bytecode:"
PUSH_SELF              ; Receiver
PUSH_ACTIVE_CONTEXT    ; Current context
PUSH 1                 ; numArgs = 1
SEND blockCopy:        ; Primitive 80 - creates BlockContext
JUMP .L_SKIP_BLOCK     ; Jump over block body

; Block body starts here (initialIP points here)
.L_BLOCK_START:
PUSH_TEMP 0            ; Load 'each' (block argument)
SEND printString       ; Send printString
RETURN_STACK_TOP       ; Block return

.L_SKIP_BLOCK:
; BlockContext now on stack
SEND do:               ; Send do: with block argument
RETURN_STACK_TOP
```

**Key Observations**:
1. `blockCopy:` (Primitive 80) creates BlockContext at runtime
2. Block body bytecode is inline, jumped over during method execution
3. BlockContext remembers `initialIP` (offset of .L_BLOCK_START)
4. BlockContext remembers `home` (defining MethodContext)
5. When block executes, it starts at saved `initialIP`

## 2. Why Single-Context Failed

### 2.1 Structural Incompatibility

**MethodContext fields** (Blue Book specification):
```
MethodContext:
  sender         - calling context (return point)
  pc             - program counter
  stackp         - stack pointer
  method         - CompiledMethod object
  receiver       - self
  [temps/stack]  - indexed slots
```

**BlockContext fields** (Blue Book specification):
```
BlockContext:
  caller         - calling context (return point)
  pc             - program counter
  stackp         - stack pointer
  nargs          - number of arguments
  initialIP      - starting bytecode offset
  home           - defining MethodContext
  [temps/stack]  - indexed slots
```

**The Problem**:
- MethodContext has `method` field → points to CompiledMethod
- BlockContext has `initialIP` + `home` fields → points to bytecode offset in parent's method
- These are **mutually exclusive** structures
- A unified context would need **both** sets of fields, but they represent different concepts

### 2.2 Semantic Incompatibility

**Method Execution**:
1. Lookup CompiledMethod in class dictionary
2. Create MethodContext
3. Set `method` field to found CompiledMethod
4. Execute bytecode from `method.bytecode[0]`

**Block Execution** (Blue Book model):
1. Block literal is just bytecode offset in current method
2. `blockCopy:` creates BlockContext with `initialIP` = offset
3. Block executes bytecode from `home.method.bytecode[initialIP]`
4. Block has NO separate CompiledMethod - reuses parent's!

**The Problem**:
- Single-context assumes blocks have separate CompiledMethods (they don't)
- Compiler would have to generate separate methods for blocks (violates Blue Book)
- Variable access model breaks (blocks use `home` chain, not lexical parent)

### 2.3 Blue Book Non-Local Return Semantics

**Blue Book specification** (Chapter 29, Primitive 80):
```smalltalk
"Non-local return from block:"
^self findDefiningMethod: blockContext home
```

**Algorithm**:
1. Block executes `^value` (return bytecode)
2. Interpreter traverses `home` chain to find defining MethodContext
3. Unwinds sender chain until reaching that MethodContext
4. Returns value to MethodContext's sender

**The Problem**:
- Single-context used `lexicalParent` instead of `home`
- But `home` is **specific to BlockContext** - it points to the **MethodContext** where block was created
- MethodContext has no `home` field (it doesn't need one - it IS home)
- Cannot unify these semantics

### 2.4 Compiler Incompatibility

**Blue Book block compilation**:
```
Source:    [:x | x + 1]
Bytecode:
  LdThisContext          ; Push current context
  PUSH 1                 ; numArgs = 1
  SEND blockCopy:        ; Create BlockContext (Primitive 80)
  JUMP 8                 ; Jump over block body
    ; Block body (embedded inline)
    PUSH_TEMP 0          ; x
    PUSH 1               ; 1
    SEND +               ; +
    EndRemote            ; Block return
  ; Jump lands here
  ; BlockContext now on stack
```

**Single-context compilation** (attempted):
```
Source:    [:x | x + 1]
Bytecode:
  PUSH_LITERAL 5         ; Literal 5 = separate CompiledMethod
  ; That's it - just push a literal
```

**The Problem**:
- Single-context requires creating separate CompiledMethod for each block
- But blocks can access parent's temps (requires `home` chain)
- Compiler would need to generate duplicate bytecode for shared methods
- Violates Blue Book specification entirely

## 3. Blue Book Specification

### 3.1 Context Structure (Chapter 30)

**MethodContext** (Blue Book lines 1205-1220):
```smalltalk
MethodContext class>>instanceVariableNames
    ^'sender pc stackp method receiver'

"Indexed slots: temporaries and stack"
```

**C# equivalent**:
```csharp
// MethodContext layout
// Instance variables (fixed slots):
const int METHODCONTEXT_SENDER_INDEX = 0;      // Return point
const int METHODCONTEXT_PC_INDEX = 1;          // Program counter
const int METHODCONTEXT_STACKP_INDEX = 2;      // Stack pointer
const int METHODCONTEXT_METHOD_INDEX = 3;      // CompiledMethod
const int METHODCONTEXT_RECEIVER_INDEX = 4;    // self

const int METHODCONTEXT_TEMP_FRAME_START = 5;  // Indexed slots start
```

**BlockContext** (Blue Book lines 1225-1245):
```smalltalk
BlockContext class>>instanceVariableNames
    ^'caller pc stackp nargs initialIP home'

"Indexed slots: arguments, temporaries, and stack"
```

**C# equivalent**:
```csharp
// BlockContext layout
// Instance variables (fixed slots):
const int BLOCKCONTEXT_CALLER_INDEX = 0;       // Return point
const int BLOCKCONTEXT_PC_INDEX = 1;           // Program counter
const int BLOCKCONTEXT_STACKP_INDEX = 2;       // Stack pointer
const int BLOCKCONTEXT_NARGS_INDEX = 3;        // Argument count
const int BLOCKCONTEXT_INITIALIP_INDEX = 4;    // Starting bytecode offset
const int BLOCKCONTEXT_HOME_INDEX = 5;         // Defining MethodContext

const int BLOCKCONTEXT_TEMP_FRAME_START = 6;   // Indexed slots start
```

### 3.2 Primitive 80: blockCopy: (Blue Book Chapter 29)

**Blue Book specification** (lines 1146-1175):
```smalltalk
primitiveBlockCopy
    | blockArgumentCount context methodContext contextSize newContext
      initialIP |

    blockArgumentCount ← self popStack.
    context ← self popStack.

    "Find home context"
    (self fetchClassOf: context) = ClassBlockContextPointer
        ifTrue: [methodContext ← self fetchPointer: HomeIndex
                                          ofObject: context]
        ifFalse: [methodContext ← context].

    contextSize ← memory fetchWordLengthOf: methodContext.
    newContext ← memory instantiateClass: ClassBlockContextPointer
                              withPointers: contextSize.

    "initialIP is offset in method's bytecode"
    initialIP ← memory integerObjectOf: instructionPointer + 3.

    "Store fields"
    memory storePointer: InitialIPIndex
                ofObject: newContext
               withValue: initialIP.
    memory storePointer: InstructionPointerIndex
                ofObject: newContext
               withValue: initialIP.
    self storeStackPointerValue: 0
                       inContext: newContext.
    memory storePointer: BlockArgumentCountIndex
                ofObject: newContext
               withValue: blockArgumentCount.
    memory storePointer: HomeIndex
                ofObject: newContext
               withValue: methodContext.

    self push: newContext
```

**Key Points**:
1. `context` parameter is current executing context (MethodContext or BlockContext)
2. If `context` is BlockContext, use its `home`; else use `context` itself
3. `initialIP` is **bytecode offset** (`instructionPointer + 3`)
4. BlockContext stores `home` (the MethodContext)
5. Returns BlockContext object

### 3.3 Primitive 81: value (Blue Book Chapter 29)

**Blue Book specification** (lines 1179-1204):
```smalltalk
primitiveValue
    | blockContext blockArgumentCount initialIP |

    blockContext ← self stackValue: argumentCount.
    blockArgumentCount ← self argumentCountOfBlock: blockContext.

    self success: argumentCount = blockArgumentCount.
    self success ifTrue: [
        "Transfer arguments from active context to block"
        self transfer: argumentCount
            fromIndex: stackPointer - argumentCount + 1
              ofObject: activeContext
              toIndex: TempFrameStart
             ofObject: blockContext.

        "Pop arguments and receiver"
        self pop: argumentCount + 1.

        "Reset IP to initialIP"
        initialIP ← self fetchPointer: InitialIPIndex
                             ofObject: blockContext.
        memory storePointer: InstructionPointerIndex
                    ofObject: blockContext
                   withValue: initialIP.

        "Set stack pointer"
        self storeStackPointerValue: argumentCount
                           inContext: blockContext.

        "Set caller"
        memory storePointer: CallerIndex
                    ofObject: blockContext
                   withValue: activeContext.

        "Activate block context"
        self newActiveContext: blockContext
    ]
```

**Key Points**:
1. Receiver is BlockContext object
2. Arguments transferred from caller to block
3. IP set to `initialIP` (bytecode offset)
4. `caller` set to current context (for return)
5. Context switch (trampoline)

### 3.4 Block Returns (Blue Book Chapter 28)

**Return bytecodes**:
```
124 (0x7C): RETURN_TOP         - Return from message
125 (0x7D): RETURN_SELF_POP    - Return self from block
```

**Algorithm** (Blue Book lines 850-900):
```smalltalk
returnBytecode
    | topOfStack context |
    topOfStack ← self popStack.

    currentBytecode = 124  "Return from message"
        ifTrue: [context ← sender]
        ifFalse: [context ← caller]. "Return from block"

    self returnTo: context withValue: topOfStack

returnTo: aContext withValue: resultPointer
    "Check if context still in sender chain"
    (self isContextUsable: aContext)
        ifTrue: [
            activeContext ← aContext.
            self push: resultPointer]
        ifFalse: [
            "Non-local return failure"
            self push: activeContext.
            self push: resultPointer.
            self sendSelector: CannotReturnSelector
                 argumentCount: 1]
```

**Key Points**:
1. Method returns go to `sender`
2. Block returns go to `caller`
3. Non-local return check: is target context still in sender chain?
4. If not, signal error

## 4. Detailed Architecture

### 4.1 Runtime Object Graph

**Method call chain**:
```
methodA  (MethodContext)
  ↓ sender
methodB  (MethodContext)
  ↓ sender
block1   (BlockContext, home → methodB)
  ↓ caller
methodC  (MethodContext)
  ↓ sender
block2   (BlockContext, home → methodC)
```

**Execution**:
1. `methodA` calls `methodB` → creates MethodContext with `sender = methodA`
2. `methodB` executes `blockCopy:` → creates BlockContext with `home = methodB`
3. `block1` is passed to `methodC` → no context created yet
4. `methodC` calls `block1 value` → creates caller link: `block1.caller = methodC`
5. `block1` executes `blockCopy:` → creates nested BlockContext with `home = block1`
6. `methodC` calls `block2 value` → creates caller link: `block2.caller = methodC`

**Non-local return from block2**:
1. `block2` executes `^result`
2. Traverse `home` chain: `block2.home = methodC`
3. `methodC` has no `home` field → it's a MethodContext → this is the defining method
4. Check if `methodC` is in sender chain starting from `block2.caller`
5. If yes: unwind to `methodC.sender`, push result
6. If no: signal error (method already returned)

### 4.2 Bytecode Structure

**Method with blocks**:
```
; Method starts
0:    PUSH_RECEIVER_VAR 0      ; Load instance variable
3:    POP_STORE_TEMP 0         ; Store to temp 0

; Block 1 creation
4:    PUSH_ACTIVE_CONTEXT      ; Bytecode 137
5:    PUSH 2                   ; numArgs = 2
7:    SEND #blockCopy:         ; Primitive 80
10:   JUMP 25                  ; Jump over block body (to offset 35)

; Block 1 body (initialIP = 12)
12:   PUSH_TEMP 0              ; Block arg 0
13:   PUSH_TEMP 1              ; Block arg 1
14:   SEND #+                  ; +
16:   PUSH_TEMP 2              ; Access method temp 0 (via home)
17:   SEND #*                  ; *
19:   ; Nested block creation
19:   PUSH_ACTIVE_CONTEXT      ; Current context (block1)
20:   PUSH 1                   ; numArgs = 1
22:   SEND #blockCopy:         ; Creates BlockContext with home = block1
25:   JUMP 10                  ; Jump over nested block body (to offset 35)

; Nested block body (initialIP = 27)
27:   PUSH_TEMP 0              ; Nested block arg 0
28:   PUSH_TEMP 1              ; Access block1 arg 0 (via home chain)
29:   SEND #+                  ; +
31:   RETURN_SELF_POP          ; Block return (bytecode 125)

; Nested block creation complete
35:   SEND #value:             ; Send value: to nested block
37:   RETURN_SELF_POP          ; Block 1 return

; Block 1 creation complete
38:   POP_STORE_TEMP 1         ; Store block1 to temp 1
39:   PUSH_TEMP 1              ; Load block1
40:   PUSH 10                  ; Arg 1
42:   PUSH 20                  ; Arg 2
44:   SEND #value:value:       ; Execute block1
46:   RETURN_TOP               ; Method return
```

**Key Observations**:
1. Block bytecode is **inline** in method bytecode
2. `JUMP` instructions skip over block bodies during method execution
3. `blockCopy:` remembers bytecode offset as `initialIP`
4. Nested blocks create BlockContexts with `home = outer BlockContext`
5. Variable access uses `home` chain to traverse scopes

### 4.3 Variable Access Algorithm

**Compiler generates indices based on local scope**:
```
Scope:               Index:
block arg 0     →    0
block arg 1     →    1
block temp 0    →    2
method temp 0   →    3  (requires home traversal)
method temp 1   →    4  (requires home traversal)
```

**Interpreter algorithm** (PUSH_TEMP bytecode):
```csharp
void PushTemporary(int index)
{
    var context = _activeContext;

    // Get local count for current context
    int localCount = GetLocalCount(context);

    if (index < localCount)
    {
        // Direct access in current context
        var value = GetIndexedSlot(context, index);
        Push(value);
    }
    else
    {
        // Access via home chain
        var homeContext = GetHome(context);
        if (homeContext == nil)
            throw new Error("Variable index out of bounds");

        // Recursively push from home context
        // (adjust index by subtracting our locals)
        PushTemporaryInContext(homeContext, index - localCount);
    }
}

int GetLocalCount(SmalltalkOOP contextOOP)
{
    var classOOP = GetClass(contextOOP);

    if (classOOP == ClassMethodContextPointer)
    {
        // MethodContext: get numArgs + numTemps from method header
        var methodOOP = GetInstanceVariable(contextOOP, METHODCONTEXT_METHOD_INDEX);
        var header = ParseMethodHeader(methodOOP);
        return header.NumArgs + header.NumTemps;
    }
    else // BlockContext
    {
        // BlockContext: get numArgs from nargs field
        var nargsOOP = GetInstanceVariable(contextOOP, BLOCKCONTEXT_NARGS_INDEX);
        int nargs = SmallIntegerValue(nargsOOP);

        // Get numTemps from home's method header
        var homeOOP = GetInstanceVariable(contextOOP, BLOCKCONTEXT_HOME_INDEX);
        var methodOOP = GetMethodFromContext(homeOOP);
        var header = ParseMethodHeader(methodOOP);

        return nargs + header.NumTemps;
    }
}

SmalltalkOOP GetHome(SmalltalkOOP contextOOP)
{
    var classOOP = GetClass(contextOOP);

    if (classOOP == ClassMethodContextPointer)
    {
        // MethodContext has no home
        return nil;
    }
    else // BlockContext
    {
        return GetInstanceVariable(contextOOP, BLOCKCONTEXT_HOME_INDEX);
    }
}
```

**Key Points**:
1. Variable access starts in current context
2. If index >= localCount, traverse `home` chain
3. MethodContext has no `home` → terminates chain
4. BlockContext has `home` → continues chain
5. Index is **relative to defining scope**, not absolute

## 5. Block Bytecode Generation

### 5.1 Compiler Architecture

**Current (Incorrect) Approach**:
```csharp
// Creates separate CompiledMethod for each block
class BytecodeCompiler
{
    void VisitBlock(BlockNode node)
    {
        // WRONG: Creates separate method
        var blockMethod = CompileToMethod(node);
        int literalIndex = AddLiteral(blockMethod);
        Emit(PUSH_LITERAL, literalIndex);
    }
}
```

**Correct (Blue Book) Approach**:
```csharp
class BytecodeCompiler
{
    void VisitBlock(BlockNode node)
    {
        // Emit blockCopy: sequence
        Emit(PUSH_ACTIVE_CONTEXT);              // Bytecode 137
        Emit(PUSH, node.Parameters.Count);      // numArgs
        EmitSend("blockCopy:", 1);              // Primitive 80

        // Reserve jump over block body
        int jumpStart = bytecodePos;
        Emit(JUMP, 0);  // Offset filled later

        // Compile block body inline
        int blockBodyStart = bytecodePos;
        foreach (var statement in node.Statements)
        {
            CompileStatement(statement);
        }

        // Block return
        Emit(RETURN_SELF_POP);  // Bytecode 125

        // Fill jump offset
        int blockBodyEnd = bytecodePos;
        int jumpOffset = blockBodyEnd - jumpStart;
        PatchJump(jumpStart, jumpOffset);

        // BlockContext now on stack
    }
}
```

### 5.2 Block Structure Examples

**Example 1: Simple block with no args/temps**
```smalltalk
[1 + 2]

Bytecode:
  ; No blockCopy: needed! Just inline execution.
  ; But to make it a first-class value, we still need blockCopy:
  PUSH_ACTIVE_CONTEXT      ; 137
  PUSH 0                   ; numArgs = 0
  SEND #blockCopy:         ; Primitive 80
  JUMP 8                   ; Jump over body
    PUSH 1                 ; Block body
    PUSH 2
    SEND #+
    RETURN_SELF_POP        ; 125
  ; BlockContext on stack
```

**Example 2: Block with arguments**
```smalltalk
[:x :y | x + y]

Bytecode:
  PUSH_ACTIVE_CONTEXT      ; 137
  PUSH 2                   ; numArgs = 2
  SEND #blockCopy:         ; Primitive 80
  JUMP 10                  ; Jump over body
    PUSH_TEMP 0            ; x (block arg 0)
    PUSH_TEMP 1            ; y (block arg 1)
    SEND #+
    RETURN_SELF_POP        ; 125
  ; BlockContext on stack
```

**Example 3: Block accessing method temp**
```smalltalk
"Method:"
| temp |
temp := 42.
[:x | x + temp]

Bytecode:
  PUSH 42
  POP_STORE_TEMP 0         ; temp := 42

  PUSH_ACTIVE_CONTEXT
  PUSH 1                   ; numArgs = 1
  SEND #blockCopy:
  JUMP 12
    PUSH_TEMP 0            ; x (block arg 0)
    PUSH_TEMP 1            ; temp (method temp 0, via home)
    SEND #+
    RETURN_SELF_POP
  ; BlockContext on stack
```

**Example 4: Nested blocks**
```smalltalk
[:x | [:y | x + y]]

Bytecode:
  ; Outer block
  PUSH_ACTIVE_CONTEXT
  PUSH 1                   ; Outer numArgs = 1
  SEND #blockCopy:
  JUMP 20                  ; Jump over outer block body

  ; Outer block body
    ; Inner block creation
    PUSH_ACTIVE_CONTEXT    ; Now refers to outer BlockContext!
    PUSH 1                 ; Inner numArgs = 1
    SEND #blockCopy:
    JUMP 10                ; Jump over inner block body

    ; Inner block body
      PUSH_TEMP 0          ; y (inner arg 0)
      PUSH_TEMP 1          ; x (outer arg 0, via home)
      SEND #+
      RETURN_SELF_POP

    ; Inner BlockContext now on stack
    RETURN_SELF_POP        ; Outer block returns inner BlockContext

  ; Outer BlockContext on stack
```

## 6. Bytecode Execution

### 6.1 Bytecode 137: PUSH_ACTIVE_CONTEXT

**Implementation**:
```csharp
case 0x89:  // PUSH_ACTIVE_CONTEXT
    Push(_activeContextOOP);
    break;
```

**Purpose**: Pushes current context onto stack for `blockCopy:` primitive

### 6.2 Bytecode 125: RETURN_SELF_POP (Block Return)

**Implementation**:
```csharp
case 0x7D:  // RETURN_SELF_POP
{
    var returnValue = Pop();

    // Check if we're in a BlockContext
    var classOOP = GetClass(_activeContextOOP);
    if (classOOP == ClassBlockContextPointer)
    {
        // Block return - go to caller
        var callerOOP = GetInstanceVariable(
            _activeContextOOP,
            BLOCKCONTEXT_CALLER_INDEX
        );

        if (callerOOP == nil)
        {
            // Error: block returned after caller died
            SignalError("cannotReturn:");
            break;
        }

        PoolContext(_activeContextOOP);
        _activeContextOOP = callerOOP;
        Push(returnValue);
    }
    else
    {
        // Method return - go to sender
        var senderOOP = GetInstanceVariable(
            _activeContextOOP,
            METHODCONTEXT_SENDER_INDEX
        );

        PoolContext(_activeContextOOP);
        _activeContextOOP = senderOOP;
        Push(returnValue);
    }

    break;
}
```

### 6.3 Bytecode 124: RETURN_TOP (Method Return with NLR support)

**Implementation**:
```csharp
case 0x7C:  // RETURN_TOP (^ from method or block)
{
    var returnValue = Pop();

    // Check context type
    var classOOP = GetClass(_activeContextOOP);

    if (classOOP == ClassMethodContextPointer)
    {
        // Normal method return
        var senderOOP = GetInstanceVariable(
            _activeContextOOP,
            METHODCONTEXT_SENDER_INDEX
        );

        PoolContext(_activeContextOOP);
        _activeContextOOP = senderOOP;
        Push(returnValue);
    }
    else // BlockContext
    {
        // Non-local return from block
        var homeOOP = GetInstanceVariable(
            _activeContextOOP,
            BLOCKCONTEXT_HOME_INDEX
        );

        // Find defining MethodContext
        var definingMethodOOP = FindDefiningMethod(homeOOP);

        // Verify it's still in sender chain
        if (!IsInSenderChain(definingMethodOOP))
        {
            SignalError("cannotReturn:");
            break;
        }

        // Unwind to defining method
        UnwindToContext(definingMethodOOP);

        // Return from defining method
        var senderOOP = GetInstanceVariable(
            definingMethodOOP,
            METHODCONTEXT_SENDER_INDEX
        );

        PoolContext(definingMethodOOP);
        _activeContextOOP = senderOOP;
        Push(returnValue);
    }

    break;
}

SmalltalkOOP FindDefiningMethod(SmalltalkOOP contextOOP)
{
    while (true)
    {
        var classOOP = GetClass(contextOOP);

        if (classOOP == ClassMethodContextPointer)
        {
            // Found the defining method
            return contextOOP;
        }

        // Traverse home chain
        contextOOP = GetInstanceVariable(
            contextOOP,
            BLOCKCONTEXT_HOME_INDEX
        );

        if (contextOOP == nil)
            throw new Error("No defining method found");
    }
}

void UnwindToContext(SmalltalkOOP targetOOP)
{
    while (_activeContextOOP != targetOOP)
    {
        var senderOOP = GetInstanceVariable(
            _activeContextOOP,
            GetSenderIndex(_activeContextOOP)
        );

        PoolContext(_activeContextOOP);
        _activeContextOOP = senderOOP;

        if (_activeContextOOP == nil)
            throw new Error("Target context not in sender chain");
    }
}

int GetSenderIndex(SmalltalkOOP contextOOP)
{
    var classOOP = GetClass(contextOOP);
    return (classOOP == ClassMethodContextPointer)
        ? METHODCONTEXT_SENDER_INDEX
        : BLOCKCONTEXT_CALLER_INDEX;
}
```

### 6.4 Jump Bytecodes

**Blue Book specification**:
- 144-151 (0x90-0x97): Short unconditional jump (1-8 bytes forward)
- 152-159 (0x98-0x9F): Short conditional jump on false (1-8 bytes forward)
- 160-167 (0xA0-0xA7): Long unconditional jump (up to 1024 bytes)
- 168-175 (0xA8-0xAF): Long conditional jump (up to 1024 bytes)

**Implementation**:
```csharp
// Short unconditional jump (144-151)
if (bytecode >= 0x90 && bytecode <= 0x97)
{
    int offset = (bytecode & 0x07) + 1;  // 1-8
    _instructionPointer += offset;
    continue;
}

// Short conditional jump on false (152-159)
if (bytecode >= 0x98 && bytecode <= 0x9F)
{
    int offset = (bytecode & 0x07) + 1;  // 1-8
    var condition = Pop();

    if (condition == SpecialObjectsArray.Instance.False)
    {
        _instructionPointer += offset;
    }
    else if (condition != SpecialObjectsArray.Instance.True)
    {
        // Not a boolean - send mustBeBoolean
        Push(condition);
        SendMustBeBoolean();
    }

    continue;
}

// Long unconditional jump (160-167)
if (bytecode >= 0xA0 && bytecode <= 0xA7)
{
    int highBits = (bytecode & 0x07) - 4;  // -4 to 3
    int lowBits = FetchByte();
    int offset = (highBits << 8) + lowBits;  // Two's complement
    _instructionPointer += offset;
    continue;
}

// Long conditional jump (168-175)
if (bytecode >= 0xA8 && bytecode <= 0xAF)
{
    int highBits = (bytecode & 0x03);
    int lowBits = FetchByte();
    int offset = (highBits << 8) + lowBits;

    var condition = Pop();
    bool jumpOnTrue = (bytecode & 0x04) != 0;  // 168-171 = true, 172-175 = false

    if ((jumpOnTrue && condition == SpecialObjectsArray.Instance.True) ||
        (!jumpOnTrue && condition == SpecialObjectsArray.Instance.False))
    {
        _instructionPointer += offset;
    }
    else if (condition != SpecialObjectsArray.Instance.True &&
             condition != SpecialObjectsArray.Instance.False)
    {
        Push(condition);
        SendMustBeBoolean();
    }

    continue;
}
```

```csharp
public static void PrimitiveBlockCopy(VirtualMachine vm)
{
    // Pop arguments
    var blockArgumentCountOOP = vm.PopStack();
    var contextOOP = vm.PopStack();

    // Validate
    if (!blockArgumentCountOOP.IsSmallInteger)
    {
        vm.PrimitiveFail();
        vm.UnPop(2);
        return;
    }

    int blockArgumentCount = blockArgumentCountOOP.SmallIntegerValue;

    // Find home context
    SmalltalkOOP methodContextOOP;
    var contextClass = vm.GetClass(contextOOP);

    if (contextClass == vm.ClassBlockContextPointer)
    {
        // Context is BlockContext - use its home
        methodContextOOP = vm.GetInstanceVariable(
            contextOOP,
            VMConstants.BLOCKCONTEXT_HOME_INDEX
        );
    }
    else if (contextClass == vm.ClassMethodContextPointer)
    {
        // Context is MethodContext - it IS the home
        methodContextOOP = contextOOP;
    }
    else
    {
        vm.PrimitiveFail();
        vm.UnPop(2);
        return;
    }

    // Get context size
    int contextSize = vm.GetWordLength(methodContextOOP);

    // Allocate BlockContext
    var newContextOOP = vm.InstantiateClass(
        vm.ClassBlockContextPointer,
        contextSize
    );

    // Calculate initialIP (current IP + 3 for blockCopy: send)
    int initialIP = vm.InstructionPointer + 3;
    var initialIPOOP = SmalltalkOOP.FromSmallInteger(initialIP);

    // Initialize BlockContext fields
    vm.SetInstanceVariable(
        newContextOOP,
        VMConstants.BLOCKCONTEXT_INITIALIP_INDEX,
        initialIPOOP
    );

    vm.SetInstanceVariable(
        newContextOOP,
        VMConstants.BLOCKCONTEXT_PC_INDEX,
        initialIPOOP
    );

    vm.SetInstanceVariable(
        newContextOOP,
        VMConstants.BLOCKCONTEXT_STACKP_INDEX,
        SmalltalkOOP.FromSmallInteger(0)
    );

    vm.SetInstanceVariable(
        newContextOOP,
        VMConstants.BLOCKCONTEXT_NARGS_INDEX,
        blockArgumentCountOOP
    );

    vm.SetInstanceVariable(
        newContextOOP,
        VMConstants.BLOCKCONTEXT_HOME_INDEX,
        methodContextOOP
    );

    // Push result
    vm.Push(newContextOOP);
}
```

**7.2.2 Primitive 81: value**

```csharp
public static void PrimitiveValue(VirtualMachine vm, int argumentCount)
{
    // Get receiver (BlockContext)
    var blockContextOOP = vm.StackValue(argumentCount);

    // Validate receiver is BlockContext
    var classOOP = vm.GetClass(blockContextOOP);
    if (classOOP != vm.ClassBlockContextPointer)
    {
        vm.PrimitiveFail();
        return;
    }

    // Get expected argument count
    var nargsOOP = vm.GetInstanceVariable(
        blockContextOOP,
        VMConstants.BLOCKCONTEXT_NARGS_INDEX
    );
    int expectedArgs = nargsOOP.SmallIntegerValue;

    // Validate argument count
    if (argumentCount != expectedArgs)
    {
        vm.PrimitiveFail();
        return;
    }

    // Transfer arguments from active context to block context
    // Source: activeContext.indexedSlots[stackPointer - argumentCount .. stackPointer - 1]
    // Dest: blockContext.indexedSlots[0 .. argumentCount - 1]
    for (int i = 0; i < argumentCount; i++)
    {
        int sourceIndex = vm.StackPointer - argumentCount + i;
        var argOOP = vm.GetContextIndexedSlot(vm.ActiveContext, sourceIndex);
        vm.SetContextIndexedSlot(blockContextOOP, i, argOOP);
    }

    // Pop arguments + receiver from stack
    vm.PopN(argumentCount + 1);

    // Reset IP to initialIP
    var initialIPOOP = vm.GetInstanceVariable(
        blockContextOOP,
        VMConstants.BLOCKCONTEXT_INITIALIP_INDEX
    );

    vm.SetInstanceVariable(
        blockContextOOP,
        VMConstants.BLOCKCONTEXT_PC_INDEX,
        initialIPOOP
    );

    // Set stack pointer to argument count
    vm.SetInstanceVariable(
        blockContextOOP,
        VMConstants.BLOCKCONTEXT_STACKP_INDEX,
        SmalltalkOOP.FromSmallInteger(argumentCount)
    );

    // Set caller to active context
    vm.SetInstanceVariable(
        blockContextOOP,
        VMConstants.BLOCKCONTEXT_CALLER_INDEX,
        vm.ActiveContext
    );

    // Switch context (trampoline)
    vm.NewActiveContext(blockContextOOP);
}
```

```csharp
void PushTemporary(int index)
{
    var contextOOP = _activeContextOOP;
    var classOOP = GetClass(contextOOP);

    while (true)
    {
        // Get local count for this context
        int localCount = GetLocalCount(contextOOP);

        if (index < localCount)
        {
            // Found it in this context
            var value = GetContextIndexedSlot(contextOOP, index);
            Push(value);
            return;
        }

        // Not in this context - traverse home chain
        if (classOOP == ClassMethodContextPointer)
        {
            // MethodContext has no home - error
            throw new InvalidOperationException(
                $"Temp index {index} out of bounds in MethodContext"
            );
        }

        // Get home
        index -= localCount;
        contextOOP = GetInstanceVariable(
            contextOOP,
            BLOCKCONTEXT_HOME_INDEX
        );

        if (contextOOP == nil)
        {
            throw new InvalidOperationException("Home chain broken");
        }

        classOOP = GetClass(contextOOP);
    }
}

int GetLocalCount(SmalltalkOOP contextOOP)
{
    var classOOP = GetClass(contextOOP);

    if (classOOP == ClassMethodContextPointer)
    {
        // MethodContext: numArgs + numTemps from method header
        var methodOOP = GetInstanceVariable(
            contextOOP,
            METHODCONTEXT_METHOD_INDEX
        );
        var header = ParseMethodHeader(methodOOP);
        return header.NumArgs + header.NumTemps;
    }
    else // BlockContext
    {
        // BlockContext: nargs + numTemps
        var nargsOOP = GetInstanceVariable(
            contextOOP,
            BLOCKCONTEXT_NARGS_INDEX
        );
        int nargs = nargsOOP.SmallIntegerValue;

        // numTemps comes from method (blocks don't declare temps separately)
        var homeOOP = GetInstanceVariable(
            contextOOP,
            BLOCKCONTEXT_HOME_INDEX
        );
        var methodOOP = GetMethodFromContext(homeOOP);
        var header = ParseMethodHeader(methodOOP);

        return nargs + header.NumTemps;
    }
}
```

## Summary

### What Failed

The **single-context architecture** attempted to merge MethodContext and BlockContext into a unified structure. This failed because:

1. **Structural incompatibility**: MethodContext uses `method` field, BlockContext uses `initialIP + home`
2. **Semantic incompatibility**: Blocks execute inline bytecode, not separate CompiledMethods
3. **Blue Book violation**: Specification requires separate context types with different fields
4. **Compiler incompatibility**: Would require generating separate methods for blocks (wrong)

### What Works

The **Blue Book two-context architecture** with:

1. **MethodContext**: For method activations
   - Has `method` field (CompiledMethod)
   - Has `sender` field (return point)
   - Has `receiver` field (self)

2. **BlockContext**: For block closures
   - Has `initialIP` field (bytecode offset in home's method)
   - Has `home` field (defining MethodContext)
   - Has `caller` field (return point)
   - Has `nargs` field (argument count)

3. **Inline block bytecode**: Generated by compiler
   - `blockCopy:` creates BlockContext at runtime
   - Block body embedded in method bytecode
   - Jump instructions control flow

4. **Variable access via home chain**:
   - Traverse `home` links to find variables
   - MethodContext has no `home` (chain terminates)
   - BlockContext has `home` (chain continues)

### Next Steps

1. Implement Primitive 80 (blockCopy:)
2. Implement Primitive 81 (value)
3. Update bytecode handlers (137, 124, 125, jumps)
4. Update compiler for inline block generation
5. Test with BlockContextTest suite

This architecture is **provably correct** because it directly implements the Blue Book specification.
