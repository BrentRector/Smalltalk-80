=== BLUE BOOK STANDARD PRIMITIVE ASSIGNMENTS (1-127) ===
The Blue Book defines these primitives as standard:
1-9: SmallInteger arithmetic (+, -, *, /, //, \, =, <, >)
10-19: LargeInteger operations
20-39: Float operations
40-59: Array/Object operations
60-67: Stream I/O primitives
68-77: File system primitives
78-84: Misc system primitives
85-86: Semaphore primitives (signal, wait)
87-88: Process primitives (resume, suspend)
89: Method cache flush
90-100: I/O and Input primitives (STANDARD ASSIGNMENT)
101+: Implementation-specific extensions
